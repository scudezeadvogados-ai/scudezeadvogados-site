Política de Privacidade

Esta página resume como dados enviados por canais de contato podem ser tratados para atendimento jurídico inicial.

Dados coletados

O site pode direcionar o usuário para WhatsApp ou e-mail. As informações enviadas voluntariamente podem incluir nome, contato, resumo do caso e outros dados necessários para análise inicial.

Finalidade

Os dados são utilizados para responder ao contato, organizar a avaliação inicial, verificar a possibilidade de atendimento e cumprir obrigações legais, éticas e profissionais.

Dados sensíveis

Casos de saúde podem envolver dados pessoais sensíveis. Por isso, documentos médicos devem ser enviados apenas após orientação sobre o canal adequado e a necessidade concreta de análise.

Compartilhamento

Dados podem ser compartilhados quando necessário para prestação de serviços jurídicos, cumprimento de obrigação legal, uso de ferramentas contratadas ou defesa de direitos, sempre observadas as regras aplicáveis.
